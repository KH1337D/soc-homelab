# SOC Home Lab

A personal Security Operations Center (SOC) home lab built to practice cybersecurity monitoring, threat detection, and incident response.

## Lab Architecture

The lab simulates an enterprise environment with the following machines:

- Kali Linux (Attacker)
- Windows 10 Target Machine
- SIEM Platform for log monitoring
- Virtualized environment

## Attack Simulations

This project includes simulations of common cyber attacks:

- Brute Force Login Attack
- Network Scanning
- Malware Execution

## Detection Use Cases

Security monitoring rules implemented:

- Multiple Failed Login Detection
- Suspicious Process Execution
- Network Scan Detection

## Tools Used

- Kali Linux
- Windows 10
- SIEM (Wazuh or Splunk)
- VirtualBox

## Skills Demonstrated

- Threat detection
- Log analysis
- Incident response
- Security monitoring
- SOC workflows
